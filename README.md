# Brianleung_Profile

A React Native + Expo profile app showcasing Brian Leung's projects and skills.

## Quick start

1. Install dependencies:

```bash
npm install
```

2. Run on iOS (requires Xcode):

```bash
npm run ios
```

3. Run on Android (requires Android Studio):

```bash
npm run android
```

4. Run on web:

```bash
npm run web
```

5. Or use Expo Go app on your phone:

```bash
npx expo start
```

Scan the QR code with your phone camera or the Expo Go app.

## Structure

- `app/(tabs)/index.tsx` — Main profile screen
- `app/_layout.tsx` — Root navigation
- `components/` — Reusable components
- `hooks/` — Custom hooks

## Built with

- Expo
- React Native
- TypeScript
- Expo Router (file-based routing)
